replay_summary.txt):

  already read the static for a player, and no consumer of the map reads players.
- hexproof-grant: resolved grants to permanents (Dive Down, Heroic Intervention, Ranger's Guile):
  hexproof_of read those before; it now also reads static rows.
- actor-antecedent: an exact target or the event (Stroke of Midnight, Ajani, Angelic Ascension,
  Gloom Sower, Liliana, Secure the Scene, Transmogrify): the antecedent always names an object.
- up-to-slot: zero chosen binds [] instead of nothing; their readers are TARGET selectors and
  IS_ANY_TARGET, which answer both alike (MTG_bot test scan, commit 3e00e709).
- multi-slot: no player slot among them, so the designated-player read is unchanged.
- another-mark (Rookie Mistake, Garruk, Savage Herald): creature filters, never the any-target
  idiom.
- reveal-until (Transmogrify): the anchors are written, and no REST reads them.
